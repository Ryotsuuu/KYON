INFORMATION-SET MCTS SEARCH LOOP
PHASE 1: PUCT TREE SELECTION
Traverse tree via PUCT: Q(s, a) + cpuct × P(s, a) × [√N(s) / (1 + N(s, a))].
Dynamic scaling: cpuct = 1.8 (early opening entropy) → 1.1 (endgame lethal convergence).
PHASE 2: FORWARD EXPANSION & SIMULATION
VirtualGameSimulator generates deterministic state transitions: evolves Pokémon, computes exact attack damage, retreat energy deductions, and prize intake.
PHASE 3: NEURAL PRIOR & VALUE EVALUATION
HiveMind NN evaluates leaf state: produces policy logits π(a|s) and scalar value V(s) ∈ [-1, +1], blended with RandomForest Card Value Model (MAE 0.0145).
PHASE 4: VIRTUAL LOSS BACKPROPAGATION
Visit count N(s, a) ← N(s, a) + 1 and cumulative value W(s, a) ← W(s, a) + V(s) backpropagated to root node. Virtual loss prevents redundant thread traversal.
